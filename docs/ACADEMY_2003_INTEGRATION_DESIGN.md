# 🎓 ハウステイトアカデミー 統合設計（packet 2003 / DESIGN ONLY）

- 起票日: 2026-06-02 ／ ステータス: **設計docsのみ・未実装**
- 自走Lv4：本書は「改善案→自己採点→より良い案→比較→最終案」を経た成果。
- ゴール: 営業トレーニング／宅建大学／実務クイズ／店長レビュー／昇格試験／ランキングを **1つの社内大学** に統合する。

> ⚠️ コード実装・DB・外部接続なし。既存OS（packet 2001 ロープレ）を土台に、静的MVP・in-memory・非破壊追加を前提に設計。

## 0. ビジョン
「**ハウステイトアカデミー**」= 新人が **宅建→実務→営業→媒介取得→買付取得** を一気通貫で学び、
**昇格（一般→主任→店長…）** まで接続される社内大学。
ロープレ（対人）・クイズ（知識）・実務（現場知）・レビュー（店長）・昇格（評価）・ランキング（動機）の6要素を統合する。

```
┌─────────────── 🎓 ハウステイトアカデミー ───────────────┐
│ 学ぶ          鍛える          試す          評価         動機       │
│ 📚宅建大学 → 🏠実務クイズ → 🎭営業ロープレ → 🎖昇格試験 ← 👑店長  │
│        ＼________ 🏆ランキング / 苦手分析 で全体を駆動 _______／      │
└──────────────────────────────────────────────┘
```

## 1. 統合で解く課題
| 現状の分断 | 統合後 |
|-----------|--------|
| ロープレと知識が別物 | ロープレ中の論点→該当クイズへ即リンク |
| 学習が評価に繋がらない | クイズ/ロープレ成績→昇格試験要件に直結 |
| 店長が個別に指導 | 店長モードが苦手を定量把握し週次課題を自動提示 |
| 続かない | ランキング・連続記録・バッジで継続を駆動 |

## 2. 統合アーキテクチャ（概念・静的MVP前提）
- **共通プロフィール層**：社員ごとの「学習・ロープレ・実務」スコア（※非PII・保存方式は承認時決定。第1弾はin-memory/デモ）
- **コンテンツ層**：宅建問題JSON／実務クイズJSON／ロープレシナリオJSON（全て静的同梱）
- **連動層**：ロープレ↔クイズの静的対応表（論点キーで紐付け）
- **評価層**：昇格試験要件エンジン（各スコアの閾値判定）
- **可視化層**：店長ダッシュボード＋ランキング
- **ナビ統合**：トップナビに「🎓 アカデミー」グループを新設し、ロープレ/宅建/実務/昇格/ランキングをぶら下げる（既存タブは非破壊維持、顧客タブは復活させない）

## 3. 統合案 A / B / C / D
### 案A：ゆるい統合（ハブページのみ）
既存ロープレ＋宅建docsへの**入口ハブ1枚**を追加。各機能は独立のまま。
### 案B：知識×ロープレ連動（実務的統合）
宅建大学(案A/B)＋実務クイズ＋ロープレを**論点リンク**で接続。店長モードは簡易版。
### 案C：評価まで接続（昇格連動）
案B＋**昇格試験要件エンジン**＋ランキング。学習・ロープレ・実務スコアが昇格に直結。
### 案D：フル統合アカデミー（共通プロフィール＋AI店長）
案C＋**共通プロフィール層**＋苦手分析＋AI店長レビュー＋月次サイクル。社内大学として完成形。

## 4. Lv4 自己採点ループ（改善の記録）
- **初版（70点）**：「全部入りの案Dを推奨」→ 採点：開発/運用コストが重く、未承認段階でリスク大。継続性に疑問。
- **改善案（85点）**：「案Bを土台に、段階的に C→D へ拡張」→ 採点：現実的だが"いつ何を出すか"が曖昧。
- **より良い案（100点狙い）**：**「案B＋ハブ(案A)を第1弾」→ Phase化でC/Dへ**。ハブで全体像を見せ、連動で価値を出し、評価/AIは後段。
- **最終採用**：下記「最終推奨」。

## 5. 最終推奨案
**段階統合：①案A(ハブ)＋案B(連動) を第1弾 → ②案C(昇格連動) → ③案D(AI店長/共通プロフィール)**

理由：
1. 第1弾(A+B)は**既存ロープリ＋静的JSONのみ**で実現でき、現方針（外部接続/DB変更なし）に完全適合。
2. ハブで「アカデミー」という世界観を即提示し、連動で**学習→ロープレ→実務**の実用価値を出す。
3. 評価(C)・AI店長(D)は効果は最大だが運用設計が要るため、効果検証後に段階投入。

## 7. ROI / 教育効果 / 売上効果（概算・前提付き）
- **教育効果**：知識×実技×評価の一体化で、新人の戦力化期間を短縮（OJT属人性の低減）。
- **売上効果**：媒介取得・買付取得の前工程スキルが標準化→**訪問査定→媒介、内覧→買付の転換率改善**が期待値。
- **ROI**：第1弾(A+B)は静的実装で開発コスト小、店長OJT工数削減だけでペイ見込み。C/Dは効果増だが運用コスト増。
