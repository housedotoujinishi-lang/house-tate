## 2. 今回カードUI化した箇所（幾何・data属性は非変更）
1. **ヘッダを白カード化**：濃紺バー → 白背景＋青見出し「👥 担当者別タイムライン（本日）」＋サブ説明「ドラッグで簡単に予定・タスクを調整」。合計件数はピル表示、切替ボタンは紺ピル（`id="stl-toggle"` 維持）。
2. **担当者名欄をアバター化**：8px の色ドット → **22px の丸アバター（メンバー色＋イニシャル）**＋名前（省略表示）。
3. **`#staff-tl` を大きめカード**：角丸14px・やわらかい影・淡い枠（CSS `!important` でインライン上書き）。
4. **行/ブロックのカード感**：`.stl-row` の罫線を薄く、偶数行の `.stl-track` に微かな色味、行ホバーで名前欄ハイライト。`.stl-blk`（タスク/予定ブロック・未割当チップ）を角丸8px＋微影で**淡いカード風**。
5. **未割当欄**：`.stl-unset` を淡い背景でカード寄せ。
6. スクロールバー視認性（2052）は維持。
