## 1. ランキング種別
| 種別 | 指標 | 狙い |
|------|------|------|
| 社員ランキング（総合） | 営業＋宅建＋実務の総合スコア | 全体の競争 |
| 部門別ランキング | 営業力／宅建力／実務力 別 | 強みで輝く場 |
| 店舗ランキング | 店舗平均・店舗合計 | 店舗対抗（多店舗時） |
| 連続学習 | 連続学習日数（ストリーク） | 毎日の習慣化 |
| 連続正解 | クイズ連続正答数 | 集中・正確性 |
| 媒介取得力 | 売却ロープレの媒介到達率・専任達成 | 売上直結スキル |
| 買付取得力 | 購入ロープレの買付/クロージング到達 | 売上直結スキル |
| 伸び率 | 前月比の改善幅 | 後発・新人も主役になれる |

## 2. ゲーミフィケーション要素
- **ポイント/XP**：学習1問・ロープレ1回・好手選択でXP付与
- **レベル/称号**：XP閾値でレベルアップ（例：見習い→主任候補→エース）
- **バッジ**：「媒介マスター」「連続7日」「模試合格」「地雷ゼロ」など
- **ストリーク**：連続学習日数のカウンタと復活猶予
- **シーズン**：月次でリセットする部門別ランキング（毎月チャンス）
- **チーム戦**：店舗対抗・班対抗（協力で全員参加）

## 3. 健全性ガード（重要）
- **量より質**：回数稼ぎを防ぐため、XPは正答率・好手率で重み付け。
- **新人配慮**：絶対値ランキングだけだとベテラン固定 → **伸び率/部門別/シーズン制**で多様な1位を用意。
- **心理的安全**：下位の晒し上げを避け、**自己ベスト更新**を前面に。最下位の固定表示はしない。

## 4. Lv4 設計プロセス
### ① 初期案
総合スコアの単純ランキング1本。
### ② 自己採点（55点）
ベテラン固定→新人の意欲低下。回数稼ぎの抜け道。晒し上げリスク。
### ③ 改善案
部門別＋伸び率＋シーズン制＋質重み付けXP＋自己ベスト主体。
### ④ 最終採用案
**総合＋部門別（営業/宅建/実務）＋媒介力/買付力＋連続記録＋伸び率＋店舗対抗**。
XPは質で重み付け、シーズンで毎月リセット、自己ベスト更新を強調。
### ⑤ 100点に近づける次改善
- ランキングを**店長レビュー/昇格要件と連動**（頑張りが評価・昇格に繋がる実利）。
- バッジを**実務スキルの証明**として人事に接続（媒介マスター＝OJT免除等）。
- 「協力ボーナス」で教え合い文化を促進（先輩が後輩を指導するとXP）。

## 5. 効果・負担・優先順位
- **教育効果**：中〜高（継続率を押し上げる＝学習総量が増える）。
- **売上貢献**：中（間接）。媒介力/買付力ランキングが実スキル意識を高める。
- **運用負担**：低〜中。集計表示中心。シーズン運用と不正防止のチューニングが必要。
- **実装優先順位**：**中**。コア（学習/ロープレ）が回り始めてから（Phase3）。先に作ると中身が空。
