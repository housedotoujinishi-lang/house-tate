- 実装日: 2026-06-02 ／ 対象: アカデミー会話型ロープレ（packet 2021 と連動）
- 目的: 結果画面だけでなく**プレイ中**に店長が介入。頻度を切替可能。

## 1. リアルタイム介入
各ターンの選択前に、状況に応じた**店長ヒント**を表示（黄色バナー「👑 杤岡: …」）。
判定（coachTip）は **現ターンの採点軸（dim）× 顧客性格 × メーター**：
| 状況 | ヒント例 | リスク |
|------|---------|:--:|
| 警戒/慎重型 ＋ クロージング軸 ＋ 信頼<55 | 「『警戒型』にクロージングは早い。まず信頼を作れ」 | ⚠ |
| 警戒心 ≥ 58 | 「警戒心が高い。今は共感を優先せよ」 | ⚠ |
| 価格軸 ＋ 競合影響 ≥ 55 | 「競合確認を忘れるな。高値合戦に乗らず根拠で」 | ⚠ |

| 期限軸 | 「期限を確認して逆算せよ」 | |

## 2. 表示頻度（切替）
プレイ画面のトグル「店長指導: OFF / 少 / 普通 / 多」（既定=普通）。
- **多**：毎ターン表示
- **普通**：偶数ターン or リスク時
- **少**：リスク時のみ
- **OFF**：非表示
（労基AIの意見：介入は学習負荷にならない頻度設計）

## 3. 結果画面の店長レビューと連携
プレイ中の指導（弱点の予防）＋ 結果画面の `personaReview`/弱点dim レビュー（事後の振り返り）で、**前後両面**から指導。

## 4. 検証
- プレイ中に店長介入が出る（頻度に応じて）／トグルで頻度変更が反映
- 顧客性格・メーターに応じてヒントが変化（警戒型クロージング/競合確認 等）
- packet2016（性格/動的採点/メーター）・2017（ホーム復帰）・2018-2020（70シナリオ/自由入力）維持
