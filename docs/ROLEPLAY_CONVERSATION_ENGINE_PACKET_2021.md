# 💬 会話型ロープレ エンジン（packet 2021）

- 実装日: 2026-06-02 ／ 対象: アカデミー選択式ロープレ（packet 2012/2016 を非破壊改修）
- 目的: 「客→回答→採点」の一問一答から、**3〜5ターンの会話**へ。顧客性格・メーターで反応が変化。

## 0. AIチーム確認結果（2021–2023 共通）
| AI | 意見 | 反映 |
|----|------|------|
| 杤岡AI店長 | 会話が続くと実戦感が上がる。指導は要点だけ（多すぎると考えなくなる） | チャットUI化＋店長指導は頻度切替（OFF/少/普通/多） |
| 九条AI | 会話でも誇大・断定は減点維持。法務観点で介入（告知/競合確認） | 反応・採点は既存維持、coachに法務系ヒント |
| 諭吉AI | 媒介/買付の前進を可視化したい | 感情に「🏷売却意欲高/🏠購入意欲高」を追加（2022） |
| 安見秘書AI | 感情が常時見えると分かりやすい。スマホでチャットが見やすく | メーター＋感情を常時表示・吹き出しUI |
| UI担当AI | 吹き出し・店長バナー・頻度トグル | 実装どおり |
| 労基AI | ルールベースで外部不要・介入は負荷にならない頻度に | 完全ローカル・頻度既定=普通 |

## 1. 会話フロー
```
お客様の発言（turn.q）
 → 営業の回答（A/B/C 選択）
 → お客様の反応（動的：性格×メーター）
 → 次のお客様の発言
 → …（テンプレの5〜6ターン）
 → クロージング → 結果
```
- 画面は**チャットログ**として蓄積表示（🧑お客様／🙋あなた／💬反応）。あなたの回答には採点バッジ（◎/△/×・点数）。
- 「次へ」ボタンを廃し、選択するとそのまま会話が続く（一問一答感を排除）。

## 2. 動的反応（reactionFlavor）
お客様の反応 = 選択肢の基本反応 ＋ **性格・メーター連動のフレーバー**：
- 地雷 → 「（表情が硬くなり距離を取られた）」（警戒心高で悪化）
- 信頼前のクロージング → 「（まだそこまでは…と警戒された）」
- 好手×信頼度高 → 「（安心した様子で本音をのぞかせた）」
- 警戒心高 → 「（まだ警戒している様子）」
→ 例：警戒型に強引クロージング＝警戒心上昇＝反応悪化／感情派に共感＝信頼上昇＝本音開示。

## 3. 維持・非破壊
- 採点（packet2015 5段階・シャッフル）、顧客性格・動的採点・メーター（packet2016）、ホーム復帰（packet2017）、70シナリオ・自由入力（packet2018-2020）は**そのまま維持**。
- 会話化は tplPlay/answer の表示・遷移のみ改修（スコアロジックは不変）。state は in-memory。

## 4. 検証
- 会話が5〜6ターン続く（テンプレのターン数）／チャットログ蓄積
- 顧客性格・メーターで反応が変化（reactionFlavor＋感情）
- `<script>`5/5・academy `node --check` PASS・CRM無傷
- 外部API/DB/localStorage本文保存なし・顧客タブ復活なし
