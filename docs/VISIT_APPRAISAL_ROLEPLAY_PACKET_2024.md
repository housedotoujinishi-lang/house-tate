# 🏠 訪問査定ロープレ 特化モード（packet 2024）

- 実装日: 2026-06-02 ／ 対象: アカデミー（packet 2012/2016/2021-2023 を非破壊拡張）
- 目的: 売上直結の **訪問査定 → 媒介取得** を訓練する専用モード。会話型（2021）＋感情（2022）＋店長介入（2023）を活用し、最後に**媒介取得判定**を出す。

## 0. AIチーム確認結果（実装前のAI会議）
**議題**: 訪問査定で媒介取得率を上げるために必要な訓練とは何か。
| AI | 意見 | 反映 |
|----|------|------|
| 杤岡AI店長 | 売却理由・期限・競合・価格期待値・不安を順に押さえてから媒介提案。早すぎる専任要求は逆効果 | 会話フローで各軸を順に。早期クロージングは性格×メーターで減点（2016/2021） |
| 九条AI | 断定/告知不要/他社批判は地雷。媒介種別（一般/専任/専属）の説明責任 | 該当はテンプレの地雷choice。判定で4種別を提示 |
| 諭吉AI | 媒介取得率＝売上直結。専任/専属を可視化 | **媒介取得判定 ❌/△/⭕/🏆** を結果に表示 |
| 安見秘書AI | 訪問査定だけの専用導線が欲しい | ホームに独立ボタン「🏠 訪問査定ロープレ」 |
| UI担当AI | 4段階判定を明確に・理由も | 判定バッジ＋理由文を表示 |
| 労基AI | 既存会話エンジン流用で低負荷 | 売却シナリオ＋会話エンジンを再利用（新規エンジンなし） |

## 1. モード
ホームに **「🏠 訪問査定ロープレ（→ 媒介取得）」** を追加（既存「📝 選択式」「✍️ 自由入力」とは別枠）。
- 売却シナリオ（売主35テンプレ）を会話型でプレイ → 最後に媒介取得判定。

## 2. ケース（20+ を網羅・既存売主35テンプレを活用）
高値売却希望／他社査定済み（競合）／相続／離婚／空き家／残債あり／任意売却／共有名義／事故物件／再建築不可／市街化調整区域／検査済証なし／築古（解体前提）／住み替え／賃貸中（オーナーチェンジ）／価格だけ知りたい（査定だけ）／売るか悩んでいる／他社専任中（媒介種別）／競合3社／急ぎ売却 …（売主35ケースで全て充足）

## 3. 流れ（会話5〜8ターン）
訪問査定開始 → 信頼構築 → 売却理由 → 所有者/権利 → 期限 → 価格期待値・競合 → 不安解消 → **媒介提案** → 結果（媒介取得判定）。
- 顧客性格・メーターで反応が変化（2021）／感情8状態を常時表示（2022）／店長がプレイ中に介入（2023）。

## 4. 採点（評価軸）
信頼構築／売却理由把握／期限把握／競合確認／価格期待値調整／不安解消／次アクション／媒介取得（売主dimにマップ：信頼構築・売却理由の深掘り・売却期限の確認・価格期待値調整/他社競合・訪問査定提案/媒介取得力）。

## 5. 地雷（減点）
必ず売れます／絶対高く売れます／他社より高いです／今すぐ専任ください／他社はダメです／問題ありません／告知不要です … はテンプレの地雷choice（性格により減点増幅）。

## 6. 媒介取得判定
結果画面に4段階を表示（理由付き）:
| 条件 | 判定 |
|------|------|
| 媒介提案（クロージング）に至らない | ❌ 媒介失敗 |
| 到達＋総合52〜69% | △ 一般媒介 |
| 到達＋総合70〜84% | ⭕ 専任媒介 |
| 到達＋総合85%以上 | 🏆 専属専任媒介 |
- 理由例：「信頼・売却理由・競合・価格調整が揃い専属専任を獲得」／「一般媒介止まり。不足: 価格期待値調整・他社競合」。

## 7. 店長介入（packet 2023 連動）
プレイ中に「競合確認が抜けている」「価格期待値の調整不足」「売却理由が浅い」「媒介提案が早すぎる（信頼前）」等を頻度切替で表示。

## 8. 検証
- 売主ケース **35（≥20）**・会話 **5〜8ターン**・感情エンジン連動・店長介入連動
- 媒介取得判定ロジック（単体テスト）: 90%+CL→🏆／74%+CL→⭕／58%+CL→△／40%+CL→❌／クロージング未到達→❌
- 既存 packet2021-2023 維持・`<script>`5/5・academy `node --check` PASS・CRM無傷
