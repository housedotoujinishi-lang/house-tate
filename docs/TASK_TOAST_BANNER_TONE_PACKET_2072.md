## 1. 目的
タスク追加トースト（packet 2063/2064）とフィルタ中バナー（packet 2066-2070）で、フィルタ状態の**用語と誘導文が不一致**だった：
- トースト：「○○**フィルタ中**…**全期間／全カテゴリをご確認ください**」
- バナー：「○○**で絞り込み中**…**「絞り込み解除」を押してください**」

→ トースト側をバナーの用語・誘導に合わせて統一する。

## 2. 変更内容（文言のみ・2トースト経路）
タスク追加トーストは2経路あった（いずれも packet 444 C案）：
- 経路A：`showKAddModal` 系（`index.html` 7117-7125・`_p444FilterWarn`）
- 経路B：左フォーム保存（`index.html` 14820-14828・`_warn`/`_toastTitleShort`）

両経路を統一：
| 箇所 | 変更前 | 変更後 |
|------|--------|--------|
| 期間警告 | ` / 期間フィルタ中` | ` / 期間で絞り込み中` |
| カテゴリ警告 | ` / カテゴリフィルタ中` | ` / カテゴリで絞り込み中` |
| 誘導文 | `。全期間／全カテゴリを(で)ご確認ください` | `。「絞り込み解除」で全件表示に戻せます` |
| 経路A 接頭 | `タスクを追加しました…` | `✅ タスクを追加しました…`（経路Bの ✅ に揃える） |

- 用語「フィルタ中」→「絞り込み中」、誘導はバナーの「絞り込み解除」ボタンに直結する表現に統一。
- 両トーストが `✅` 始まりに揃い、フィルタ語もバナー（`tfb-kind`：期間で絞り込み中 等）と一致。
- **ロジック・`taskFilter`・保存・タブ判定・showToast 呼び出し構造は非変更**。文言のみ。
