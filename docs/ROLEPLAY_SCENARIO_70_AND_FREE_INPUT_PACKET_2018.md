## 0. AIチーム確認結果（実装前のAI会議）
**議題**: シナリオ大幅増量と自由入力ロープレをどう実装すべきか。
| AI | 意見 | 反映 |
|----|------|------|
| 杤岡AI店長 | 実戦ケースを網羅（調停中/相続人4人/共有/任意売却/事故物件/ゴミ屋敷等）。各問に地雷 | 売主35・買主35。実戦/法務ケースを追加。各設問に地雷 |
| 九条AI(宅建) | 事故物件・告知・検査済証・越境は**隠蔽/断定をNGワード地雷**化。自由入力でも法務リスク減点を必須に | 該当ケースの隠蔽choice＝地雷／自由入力に NG_WORDS・法務配慮軸を実装 |
| 諭吉AI(KPI) | 媒介取得/訪問査定/買付の前進を加点軸に | 選択式のクロージング軸＋自由入力の「次アクション」軸（最大+20） |
| 安見秘書AI | 自由入力はスマホで打ちやすく・再回答容易に | 大きめ textarea・「↻ 再回答」「次へ」ボタン |
| UI担当AI | 選択式と自由入力をホームで明確分離・全画面に🎓TOP | ホームを「📝選択式」「✍️自由入力」に分割／free画面にも backBar |
| 労基AI | 外部API不要のローカル採点で保守軽量に | OpenAI等不使用のルールベース採点で実装 |

## 1. シナリオ70+（20+20 → 35+35＝70）
### 売主35（+15）
既存20 ＋ **離婚調停中／相続人4人以上／共有名義／空き家10年放置／ゴミ屋敷／再建築不可／連棟／市街化調整区域／任意売却／事故物件／境界未確定／検査済証なし／越境あり／解体前提／農地**
### 買主35（+15）
既存20 ＋ **子供出生予定／ローン否決歴／法人購入／セカンドハウス／フルローン／頭金ゼロ／投資初心者／利回り重視／駅距離重視／夫婦ペアローン／現金購入／注文住宅／マンション派／高齢ダウンサイジング／単身購入**
- 各テンプレは別論点（水増しなし）。事故物件/告知/検査済証/越境/任意売却は法務重め。
- **隠蔽・断定choiceを地雷化**（例: 事故物件「黙っておけば大丈夫」、検査済証なし「問題ありませんよ」、高値「必ず高く売れます」）。
- A/B/C選択式・顧客性格8類型・動的採点・メーター（2016）・ホーム復帰（2017）を維持。生成時シャッフルでB偏重なし（2015）。

## 2. 自由入力ロープレ（packet 2019・ルールベース・外部API不使用）
### 流れ
お客様の発言（性格・感情・状況）を表示 → **textarea で自由入力** → 「採点する」→ AI店長レビュー風カード（採点/良かった点/危険な点/改善例/模範解答/杤岡レビュー）→「↻ 再回答」または「次のお客様へ」。
### 採点軸（ローカル・キーワードベース）
共感／深掘り(質問)／次アクション／法務配慮／不安を拾う／断定回避／顧客性格適合。
- 共感: お気持ち/ご不安/お察し/大変… → +15
- 深掘り: ？/ですか/教えて/なぜ/いつ… → +15
- 次アクション: 訪問査定/内覧/事前審査/媒介/現地… → +20（媒介取得/訪問査定/買付の前進）
- 法務配慮: 告知/重要事項/確認/司法書士/登記/測量… → +15
- 性格適合: 警戒/慎重型に共感なしのクロージング=減点、論理派に根拠/確認なし=減点、感情派に共感=加点、忙しい型に冗長=減点。
### NGワード地雷（各 −25）
必ず売れます／絶対大丈夫／黙っておきましょう／すぐ契約しましょう／他社より必ず高く売ります／ローンは絶対通ります／問題ありません／違法ではありません／告知しなくていいです（ほか）。
### 店長レビュー（杤岡AI・例）
「共感はできているが、次アクションが弱い」「事情の深掘りが不足」「『警戒型』にはクロージングが早すぎる」「論理派には根拠・確認・数字を」「感情派の不安を先に拾え」「断定・告知軽視は厳禁（法務リスク）」。
### 改善例
そのターンの**最適choice（模範解答）**を提示し、すぐ学べる。

## 3. UI（packet 2020）
- ホームを **「📝 選択式ロープレ（A/B/C）」** と **「✍️ 自由入力ロープレ（AI店長レビュー）」** に明確分離。
- 自由入力モードにも sticky **「🎓 アカデミーTOPへ」**（backBar）。スマホで打ちやすい大きめ textarea。採点はカード表示。再回答が1タップ。

## 4. 検証
- 売主テンプレ **35**・買主テンプレ **35**・合計 **70**（grep確認）
- A/B/C選択式・packet2016（性格/動的採点/メーター）・packet2017（ホーム復帰）維持
- 自由入力で採点結果が出る（採点カード/各軸/良かった点/危険な点/改善例/杤岡レビュー）
- **NGワード減点が効く**（NG2語の回答＝−50、良い回答＝+50：単体テスト確認）
- **法務リスク地雷が効く**（告知軽視/断定がNGワードで大幅減点＋危険な点に明示）
- `<script>` タグ 5/5一致・academy block `node --check` PASS・CRM非表示マーカー無傷
