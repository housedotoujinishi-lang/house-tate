# 🔎 スケジュールブロック可読性強化（packet 2028）

- 実装日: 2026-06-02 ／ 対象: `buildTimeline`（packet2014・**日表示タイムライン＋タスクボードboard 共有**）
- 目的: 「誰が何をしているか」を**3秒で把握**できるブロック表示へ。

## 1. 背景（現状の問題）
- 旧ブロック：幅＝所要時間比例（30分=30px・最小18px）、高さ24px・1行・`nowrap+overflow:hidden`。
- → 短時間ブロックは時刻(9px)でほぼ埋まり**予定名が切れて読めない**。tooltipはhover前提でスマホ不可。

## 2. 実装（S＋A・可読性優先）
### 優先度S
- **2段ブロック化**：1段目＝`種別アイコン＋⏰開始時刻`（太字）／2段目＝`予定名`（`text-overflow:ellipsis`）。高さ `BLOCKH 24→38`。
- **最小幅 18→64px（MINW）**：短時間でも名称が読める。位置は時刻で正確、重なりは既存`assignLanes`で**縦レーン**に逃がす。
- **ルーティンも名称表示**：📋＋ルーティン名（既存`fromRoutine`）。
### 優先度A
- **hover詳細**：`title`属性を強化（`開始〜終了 ／ 予定名 ／ 種別 ／ 担当者`）。PCはhoverで全文、スマホは2段ブロックで名称が常時可視。
- **種別アイコン色強化**：📞架電／🤝追客／🔍査定・訪問／📄物件・資料／🏠内見／👥MTG・朝礼／📋ルーティン／▫その他（左ボーダー色は従来維持）。
- **担当者ごと空き率**：氏名下に「空き◯%」＋稼働ミニバー。算出＝`1−稼働分/(8-18の600分)`。緑(≥50%)/橙(20-50%)/赤(<20%)で「詰まってる/空いてる」が一目。

## 3. 共有改修の効果
`buildTimeline` は**日表示タイムライン(packet2014)とタスクボード常設ボード(packet2027)の共有関数**のため、**両画面が同時に見やすく**なる。色・データ・D&D・採点・件数ロジックは不変（表示のみ強化）。

## 4. 検証
- `node --check`（packet2014ブロック）PASS・`<script>` 7/7一致・禁止APIトークン0件・CRM無傷
- 空き率ロジック単体：予定3本(計3h)→空き60%／0本→100%／終日(10h)→0%
- 期待：各ブロックに「種別アイコン＋時刻」「予定名」が読める／ルーティン名表示／hover(PC)で詳細／空き率バッジ表示／月週日・既存D&D・件数 無改変

## 5. トレードオフ
- 可読性優先（最小幅64px）：時間幅の厳密さより「3秒把握」を優先。隣接の視覚的近接は縦レーンで回避。行は2段＋レーンで縦に伸びる（情報密度UPの許容）。
