# 😊 感情エンジン強化（packet 2022）

- 実装日: 2026-06-02 ／ 対象: アカデミー `emotionFor()`（packet 2016 を強化）
- 目的: 感情表現を4状態から**8状態**へ。メーターから自動判定し常時表示。

## 1. 8つの感情状態
🛡 警戒 ／ 🤨 半信半疑 ／ 👂 興味あり ／ 🙂 好印象 ／ 🤝 信頼 ／ 🔥 前向き ／ 🏷 売却意欲高 ／ 🏠 購入意欲高

## 2. 判定ロジック（信頼度/警戒心/温度感/緊急度/競合＋側＋クロージング）
| 条件（優先順） | 感情 |
|----|------|
| 警戒心 ≥ 62 | 🛡 警戒 |
| 信頼<42 かつ 警戒≥46 | 🤨 半信半疑 |
| 信頼≥66 かつ（クロージング到達 or 緊急≥64） | 🏷 売却意欲高 / 🏠 購入意欲高（側で出し分け） |
| 信頼 ≥ 64 | 🤝 信頼 |
| 温度≥60 or 緊急≥58 | 🔥 前向き |
| 信頼 ≥ 50 | 🙂 好印象 |
| 緊急≥44 or 温度≥46 | 👂 興味あり |
| それ以外 | 🤨 半信半疑 |

## 3. 表示・連動
- プレイ画面・自由入力画面のメーターバーに**常時表示**。
- 回答ごとにメーターが動き、感情が即時に変化（packet 2021 の会話反応と連動）。
- 「🏷売却意欲高/🏠購入意欲高」で**媒介取得/買付取得の前進**を可視化（諭吉AIの意見反映）。

## 4. 検証（単体テスト）
- 警戒型初期(guard70) → 🛡 警戒
- 信頼構築後(trust68) → 🤝 信頼
- クロージング到達(trust70,closing,sell) → 🏷 売却意欲高
- 中立(trust50) → 🙂 好印象
- `<script>`5/5・academy `node --check` PASS・CRM無傷・外部接続/保存なし

## 5. 非破壊
- `emotionFor()` の差し替えのみ。メーター（packet2016）・会話（2021）・自由入力（2019）に共通適用。state は in-memory。
