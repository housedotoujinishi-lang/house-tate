# 担当者別タイムライン 縦カラムカード化 MVP（packet 2054）

## 1. 採用案と理由
- 既存の担当者別タイムラインは「**行＝担当者・横軸＝時間**」の構造で、ブロックは絶対座標（`left/top/width`＝HOURWベース）で配置され、ドラッグ座標系がこのDOMに依存。
- CSSだけで「縦カラム」へ転置するのは不可能（DOM順序が行ベース）。座標系の作り替え（案A的な本体改修）は**ドラッグ破壊リスクが高い**。
- → **案B（最も安全）を自動選択**：既存タイムライン本体（ドラッグ用）は**一切触らず**、同じ `rowsData` から**表示専用の「担当者別カードビュー」**を生成して上に追加。read-only でドラッグ・保存に非依存。

## 2. 実装内容（純追加・read-only）
- `buildTimeline()` 内で、既存 `rowsData`（`r.mem{n,c}` / `r.timed[]` / `r.unset[]` / `r.count`）を**流用**して `cardViewHtml` を生成。
- 注入位置：`#staff-tl` の件数バーの直下、既存の時間軸 `.stl-scroll` の**上**。時間軸側には小見出し「🕓 時間軸（ドラッグで編集）」を付与。
- カードビュー構造（**新クラス `.stlc-*` のみ**・`stl-blk`/`data-*` は不使用）：
  - `.stlc-wrap`（横スクロール）→ `.stlc-row`（flex）→ 担当者ごとに `.stlc-col`（縦カラムカード）。
  - カラム上部 `.stlc-colhead`：丸アバター（メンバー色＋イニシャル）＋名前＋件数バッジ。カラム上辺に担当者色のアクセント（`border-top:3px`）。
  - `.stlc-body`：その担当者のタスク/予定を**時刻順に縦積みカード** `.stlc-card`（時刻＋カテゴリ色アクセント＋タイトル2行）。時間未設定は「🕓 時間未設定」カード。0件は「予定なし」。
  - 既存のカテゴリ色（`bucket`）・アイコン（`catIcon`）・エスケープ（`esc`）を流用。
- 見た目：白カラムカード・淡い背景・角丸・余白広め・薄い罫線・担当者ごとに上辺色を変える・横スクロール（多人数時）。各カラムは縦スクロール（タスク多数時 `max-height:380px`）。

## 3. ドラッグ維持（変更禁止箇所を非編集）
- 既存 `.stl-scroll`/`.stl-row`/`.stl-track`/`.stl-blk`＋`data-kind`/`data-s`/`data-e`/`data-id`、`.stl-move`/`.stl-rsz`/`.stl-chk`、絶対座標（HOURW=260/BLOCKH）… **すべて非編集**。
- カードビューは**別クラス `.stlc-*`・data属性なし**のため、`.stl-blk` を参照する pointer ドラッグ/リサイズ/完了ハンドラは**カードビューを一切拾わない**（混入0を grep 確認）。
- read-only（クリックで保存/変更を起こさない）。`buildTimeline`/`renderTaskBoard`/`bindChk`/`_persistTasks` は非編集（HTML文字列にカードビュー生成を追加しただけ）。
