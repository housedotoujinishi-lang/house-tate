# タスクボード 4エリア再設計MVP「迷子にならない今日やることナビ」（packet 2050）

- 種別：**UI/UX 表示改善 MVP（追加のみ・非破壊）**
- 日付：2026-06-06
- 対象：タスクボード（`#page-cal` 内 `#tb-panel`）
- 方針：既存タスクデータ・保存・完了・ドラッグ・カレンダー・ルーティンを**一切触らず**、4エリア思想の「見出し＋導線＋説明」を上部に追加する。

---

## 1. 目的
社員が朝見た瞬間に「今どこを見る／迷ったらどこに書く／完了したらどうする」が分かるよう、
タスクボードを **4エリア思想**へ寄せる。今回は **表示・導線・説明文 MVP**（重い自動分類・データ移行は後回し）。

## 2. 4エリア構成（思想）
| エリア | 役割 | 既存機能との対応 |
|--------|------|----------------|
| ① 今日の流れ（ここだけ見る） | 時間順・アイコン中心・☐/✅/⚠ | 既存のタスク一覧/カンバン/タイムライン（`#tb-body`） |
| ② 割り込みメモ（考えず書く） | 電話/LINE/急依頼/思いつき/URL | 既存メモ（`switchPage('memo')`・対応要メモストリップ） |
| ③ あとでやる箱（決まったら→①） | 日時が決まったタスク | 既存タスク（期限/未割当） |
| ④ 毎日の型（ルーティン原本） | 朝礼/未完了確認/日報準備等 | 既存ルーティン（`appendRoutineToTaskBoard`・`switchPage('routine')`） |

## 3. 実装内容（index.html・追加のみ）
1. **タイトル改名**：`.tbt` 「📋 タスクボード」→「🧭 今日やることナビ」（1行）。
2. **4エリア・ナビ見出しバナー**を `.tbh`（ヘッダ）直後・`.tbform`（入力）直前に挿入（静的HTML）。
   - `<details class="tyn-nav-wrap" open>` で**折りたたみ可能**（初期は開）。
   - 使い方1行ガイド＋4エリアカード（各：濃い背景＋白文字の見出し＋一言説明）＋凡例（種類/状態）。
   - 種類凡例：🔵ルーティン 🔴突発タスク 🟡今日中 ⚪空き・復帰枠。
   - 状態凡例：☐まだ ✅終わった ⚠詰まった（3択中心）。
   - 導線：②に「▶ メモ帳へ」（既存 `switchPage('memo')`）、④に「▶ ルーティン編集」（既存 `switchPage('routine')`）を再利用（新規関数なし）。
3. **CSS追加**（メイン `<style>` 末尾、`.tyn-*`）：濃い背景見出し（①紺/②橙/③緑/④紫）＋白文字、カード間6pxの細い隙間、情報を詰め込みすぎない小さめフォント。

## 4. スマホ表示
- `.tyn-areas` は `flex-wrap`。`@media(max-width:700px)` で各エリアカードを **1列縦並び**（`flex:1 1 100%`）に。横並びにしない。
- バナー全体は `<details>` で**折りたたみ可能**＝入力パネルの邪魔になりにくい。
- ※実機のスマホ表示崩れは目視確認推奨（下記チェック項目）。
