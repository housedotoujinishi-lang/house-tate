# 担当者別タイムライン 横スクロール復旧＋カード化 hotfix/MVP（packet 2052）

- 種別：**hotfix（横スクロール復旧）＋UI改善（カード化）。CSSのみ・JS非編集**
- 日付：2026-06-07
- 対象：担当者別タイムライン（`#cal-view .daycol > #staff-tl > .stl-scroll`）
- 参考：ボス提供UI画像（git管理外）

---

## 1. 原因（横スクロールできなかった理由）
- 担当者別タイムラインは**カレンダーの日表示**内に注入される：`#cal-view .daycol` → `#staff-tl` → `.stl-scroll`（`overflow-x:auto`・内側 `min-width = NAMEW+UNSETW+timeW ≒ 4364px`、HOURW=260×16h）。
- `.stl-scroll` 自体は正しく `overflow-x:auto` を持つが、**祖先がその幅を制約していなかった**：
  - `#cal-layout` のグリッド列が `1fr`（＝ `minmax(auto,1fr)`）。グリッド/フレックス項目の既定 `min-width:auto` により、**カレンダー列が内容幅（約4364px）まで膨張**。
  - 膨張した分を `body{overflow-x:hidden}`（9行）が**クリップ**＝右側が見えず、スクロールも不可。
- つまり「`.stl-scroll` が内部スクロールするための“制約された幅”」が祖先で潰れていたのが根因。

## 2. 横スクロール修正内容（修正方針A・CSSのみ）
- `#cal-layout` のグリッド列を `1fr` → **`minmax(0,1fr)`**（`both`/`board`/`calonly`＋スマホ `both!important`）。列が内容幅まで膨張せず**ビューポート幅に制約**される。
- 祖先に **`min-width:0`**：`.calr`（`display:flex;flex-direction:column` のグリッド項目）と `.daycol`。フレックス/グリッド子が内容より小さくなれるようにし、`.stl-scroll` の内部スクロールを有効化。
- `.stl-scroll{max-width:100%; overscroll-behavior-x:contain}`。
- 結果：カレンダー列はビューポート幅に収まり、**タイムラインは `.stl-scroll` 内で横スクロール**（右側の時間軸まで到達可能）。PCはトラックパッド/Shift+ホイール/スクロールバー、スマホは横スワイプ。
- **`.stl-scroll` のインラインスタイル・`buildTimeline`・ドラッグ/pointer 関数・HOURW 定数は一切編集していない**（競合回避のため表示側のみ修正）。

## 3. 下段UIを参考画像に寄せた内容（修正方針B・CSSのみ）
- `#staff-tl`：`box-shadow:0 1px 5px rgba(15,23,42,.08)`＋下マージンで**カード感**（白背景・角丸・薄い影）。既存の白背景/角丸/見出し(#0a3d7c)は活かす。
- `.stl-scroll` の**横スクロールバーを視認しやすく**：`scrollbar-width:thin`／`::-webkit-scrollbar`（高さ10px・つまみ#cbd5e1・トラック#f1f5f9）。「ここは横に動く」と分かるように。
- ※ 担当者カラムの個別カード化・タスクブロックの余白増・未割当カードのカード化/0件チェックマークは、**`buildTimeline` のインライン生成（ドラッグ依存DOM）に踏み込む必要があり、今回は安全のため見送り**（次packet候補）。

## 4. 表示モード別の挙動
- 🧭 タスクのみ（`board`）：カレンダー側（`#cal-right`）が `display:none` のため**担当者別タイムラインは非表示**（元々カレンダー日表示の機能）。タスクボードは全幅。
  - ※ 画像のように「タスクのみ」内へ独立タイムラインを置くのは構造変更（注入先の移動）になるため次packet候補。
- 📅 カレンダーのみ（`calonly`）：カレンダー全幅。日表示でタイムラインが**横スクロール可能**。レイアウト崩れなし（`minmax(0,1fr)`）。
- 📅＋🧭 両方（`both`）：左タスク300px＋カレンダー `minmax(0,1fr)`。日表示でタイムラインが**横スクロール可能**。
- スマホ：`both` は縦積み（`minmax(0,1fr)!important`）。`.stl-scroll` 対象だけ横スワイプ。
