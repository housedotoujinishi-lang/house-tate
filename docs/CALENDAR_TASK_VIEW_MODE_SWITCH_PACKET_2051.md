# 表示モード切替強化：カレンダーのみ／タスクのみ／カレンダー＋タスク（packet 2051）

- 対象：`#page-cal`（今日やることナビ／カレンダー）
- 参考：ボス提供のUI参考画像（`767f21a9-...png`・**git管理外**）。画像上部の3モードボタンに準拠。

## 1. 目的
カレンダー・タスク入力・担当者タイムライン・未割当タスクが同時表示で狭い問題を、
**3つの表示モードを直感的に切替**できるようにして解決する。既存ロジックは壊さない。

## 2. 調査した既存切替ロジック
- `layoutMode`（既定 `'both'`、init で `setLayout('both')` 実行）。
- `setLayout(mode)`：`#cal-layout` の class を `both`/`board` に切替、`#cal-right`（カレンダー）を表示/`display:none`、`#tb-body` を通常/`grid`。
- ボタン：`lay-both`（＋カレンダー）/`lay-board`（ボードのみ）、`.lbtn` クラス。**スマホでは `.lbtn{display:none}`＝切替不可だった**。
- CSS：`.cal-layout.both{256px 1fr}` / `.board{1fr}`、スマホは `both` を `1fr!important`。
- `render()` は `layoutMode==='both'` のときだけ `renderCal()`。

## 3. 実装（3モード化・追加/最小改変）
### モード
| モード | ボタン（画像準拠） | 動作 |
|--------|------------------|------|
| `board` | 🧭 タスクのみ | カレンダー非表示・タスクボード全幅（`#tb-body` grid） |
| `cal` | 📅 カレンダーのみ | **新規**。タスク側(`#tb-panel`)を`display:none`・カレンダー全幅 |
| `both` | 📅＋🧭 カレンダー＋タスク | 両方表示。左タスク幅を **256px→300px** に拡張 |

### 変更点
- **モード切替バーを新設**：`#cal-layout` の**直上**に常時表示の `.vmode-bar`（3ボタン）。
  - これにより「カレンダーのみ」で `#tb-panel` を隠してもボタンが消えず**切替可能**（旧ボタンはパネル内にあり隠れる問題を解消）。
  - ボタンidは既存 `lay-both`/`lay-board` を**流用**（既存onclick・burst演出 `#lay-both` と互換）＋ `lay-cal` 追加。
  - 旧 `.tbhl` 内の `.lbtn` 2ボタンは撤去（タイトルのみ残す）。
- `setLayout(mode)` を3分岐に書き換え（`cal`/`both`/`board`）。`#tb-panel` の表示/非表示制御を追加。ボタンは `.vmode-btn` クラスで状態表示。
- `cal`/`both` 進入時に `renderCal()`（＋日表示以外で `renderPoolPreview()`）を guard 付きで呼び、カレンダー最新化。
- `render()` の描画条件を `both` → `both||cal` に拡張（モード`cal`でも月送り等で再描画される）。
- `lay-cal` の onclick を追加（`setLayout('cal')`）。

### 色と見た目（画像準拠）
- `.vmode-bar`：淡い背景＋下境界。`.vmode-btn`：白地・丸ピル。**選択中は濃い背景(#0a3d7c)＋白文字**。

## 4. スマホ表示
- `.vmode-bar` は `.lbtn` と別クラスのため**スマホでも表示**（旧仕様はスマホ切替不可だった→改善）。`@media(max-width:700px)` でボタンを横いっぱいに均等配置。
- `cal`/`board` はスマホでも単体全幅で破綻しにくい。`both` はスマホで従来どおり `1fr!important`＝縦積み。
