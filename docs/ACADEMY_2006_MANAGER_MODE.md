# 👑 店長モード設計（packet 2006 / DESIGN ONLY）

- 起票日: 2026-06-02 ／ ステータス: **設計docsのみ・未実装**
- 対象: 杤岡店長（管理者/owner権限）。アカデミー全体（ロープレ/宅建/実務）の社員育成を統括。
- 既存OSの権限: `currentUser.perm==='admin'|'owner'` または role に「店長」を含む（packet 2001で判定実装済）。

> ⚠️ docs設計のみ。実装・DB・外部接続なし。社員データは**非PII・保存方式は承認時決定**（第1弾はin-memory/デモ集計）。

---

## 1. 目的
店長が「**誰が・何を・どれだけ**できる/できないか」を一目で把握し、**指導を定量化**する。
属人OJTを、データに基づく週次・月次のレビューサイクルへ。

## 2. 分析ディメンション（社員別）
| 軸 | 指標 | データ源 |
|----|------|---------|
| 営業（ロープレ） | 隠し情報回収率・地雷回避率・クロージング到達・売却ゴール達成 | packet 2001 |
| 宅建 | 分野別正答率・模試合格回数・苦手論点 | packet 2004 |
| 実務 | テーマ別正答率（媒介/契約/法令…） | packet 2005 |
| 得意/苦手 | 上記の偏差から自動抽出（強み・弱み TOP3） | 集計 |
| 学習量 | 学習日数・連続日数・所要時間 | 集計 |

## 3. 画面構成
1. **チーム俯瞰**：社員一覧×（営業/宅建/実務）スコアのヒートマップ、クラス平均、伸び率
2. **社員ドリルダウン**：個人の得意/苦手レーダー、弱点論点、今週の課題、履歴
3. **週次レビュー**：今週の学習・ロープレ実績サマリ＋自動コメント草案＋店長手動コメント欄
4. **月次レビュー**：到達度の推移、昇格要件への距離（packet 2008連携）、来月の重点
5. **AI店長（将来）**：弱点から指導コメントを自動生成（※AI接続は現状禁止 → 第1弾は定型テンプレ）

## 4. 指導コメント（第1弾＝定型テンプレ方式）
- 弱点タグ→定型文の対応表で**コメント草案**を生成（AI不要）。
  - 例: 「媒介クイズ正答率<60%」→「専任/専属専任の報告頻度とレインズ登録期限を再確認。S04/S05ロープレで実戦を」
- 店長が草案を編集して確定（人の判断を残す）。

## 5. AI店長（将来構想・解禁後）
- 既存「🧠 AI会議」の枠組みを流用し、弱点データから指導方針を生成。
- 現状はAI接続禁止のため**設計のみ**。第1弾は定型テンプレで代替。

## 6. Lv4 設計プロセス
### ① 初期案
社員一覧に総合点だけ並べるシンプル版。
### ② 自己採点（60点）
総合点だけでは「何を指導すべきか」が分からない。行動に繋がらない。
### ③ 改善案
営業/宅建/実務の3軸分解＋弱点TOP3＋今週の課題の自動提示。
### ④ 最終採用案
**3軸ヒートマップ＋個人ドリルダウン＋週次/月次レビュー＋定型指導コメント草案**。
昇格要件への距離も表示（2008連携）。AI店長は後段。
### ⑤ 100点に近づける次改善
- ロープレと宅建/実務の**相関**を見せる（例：媒介クイズ弱い人は媒介ロープレも弱い→重点指導）。
- 「指導→翌週の改善度」を追跡し、**指導の効果測定**まで回す。
- 社員本人にも自分の弱点を共有し、自己学習を促す双方向化。

## 7. 効果・負担・優先順位
- **教育効果**：高。弱点が可視化され指導が的を射る。OJTの再現性が上がる。
- **売上貢献**：中〜高（間接）。媒介/買付の前工程スキルの底上げが成約率に効く。
- **運用負担**：中。週次/月次のレビュー運用が必要。ただし草案自動生成で軽減。
- **実装優先順位**：**高**（アカデミーの"評価ハブ"。ランキング/昇格の土台）。Phase2で投入推奨。
